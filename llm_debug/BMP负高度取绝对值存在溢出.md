# BMP 顶向下高度取反可能发生有符号溢出

> **核对 2026-11-15**：✅ 已修 —— `src/draw/qlimage.c:233-238` 先拒绝 `INT32_MIN` 再取反

## 问题位置

- `src/draw/qlimage.c`：`decode_bmp()`

## 问题说明

对 `BITMAPINFOHEADER` 中的高度，解码器先将无符号头字段转换为 `int32_t`，若高度为负则执行 `h = -h`。当头字段为 `0x80000000` 且实现将其转换为 `INT32_MIN` 时，取反无法由 `int32_t` 表示，触发有符号溢出的未定义行为。该值后续才会经过尺寸上限校验。

## 影响

特定异常 BMP 高度可能触发未定义行为，导致解码结果不可靠或进程崩溃。

## 检查状态

由高度解析和取反顺序静态确认；没有修改项目代码。
