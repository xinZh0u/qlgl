# ql_input_push_text 可能在 UTF-8 码点中间截断输入文本

## 问题

`ql_input_push_text()` 将 UTF-8 字节逐个复制到固定大小的事件文本缓冲区，达到容量上限时直接停止，没有把截断长度退回到完整码点边界。

## 影响

长输入文本在缓冲区末端遇到多字节字符时会生成无效 UTF-8 事件。下游控件会收到不完整字符，造成显示或编辑异常。

## 依据

- `src/core/qlinput.c` 的 `ql_input_push_text()` 按字节循环，循环条件仅保留一个 NUL 字节，没有使用 `ql_utf8_valid_len()` 或其他码点边界检查。

## 验证状态

静态追踪确认输入事件文本可能截断在多字节码点中；现有输入测试通过，本次未构造边界截断样本动态验证。
