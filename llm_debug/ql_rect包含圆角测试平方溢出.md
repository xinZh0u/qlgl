# `ql_rect_contains_round()` 使用 32 位乘法计算距离平方

## 问题位置

- `src/draw/qlgeom.c`：`ql_rect_contains_round()`

## 问题说明

函数将 `dx`、`dy`、`radius` 都保存为 32 位有符号 `ql_coord_t`，并直接计算 `dx * dx + dy * dy <= radius * radius`。当圆角半径超过约 46340 时，平方就可能超出 `int32_t` 范围；有效的大矩形/大半径因此触发有符号溢出，属于未定义行为。

## 影响

大坐标尺度下的圆角矩形命中测试结果不可靠，可能错误地把点判为矩形内或外；优化构建下结果也可能变化。常见小窗口尺寸不受影响。

## 检查状态

由表达式整数类型与溢出边界静态确认；没有修改项目代码。
