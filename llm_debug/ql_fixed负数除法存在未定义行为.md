# `ql_fixed_div()` 对负分子执行有符号左移，行为未定义

## 问题位置

- `src/core/qlvalue.c`：`ql_fixed_div()`

## 问题说明

`ql_fixed_div()` 用 `((int64_t)a << QL_FIXED_SHIFT)` 构造被除数。C 标准不定义对负的有符号整数执行左移的结果；负数定点值是该 API 的正常输入，因此即使不发生数值溢出，常见的负数除法路径也可能触发未定义行为。

## 影响

负数定点除法的结果依赖编译器/优化器行为。常见正数范围内的现有测试未覆盖该情形。

## 检查状态

由 C 有符号算术规则静态确认；没有修改项目代码。
