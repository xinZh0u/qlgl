# BMP DIB 头尺寸加法溢出可绕过输入长度检查

> **核对 2026-11-15**：✅ 已修 —— `src/draw/qlimage.c:208-210` 用 64 位比较 `hdr_size + 14`

## 问题位置

- `src/draw/qlimage.c`：`decode_bmp()`

## 问题说明

解码器使用 `n < 14u + hdr_size` 检查 DIB 头是否完整，其中 `hdr_size` 是从输入读取的 32 位无符号值。`14u + hdr_size` 在 32 位无符号算术中可能回绕为很小的值，令短输入通过检查；随后，`hdr_size >= 40` 分支仍会读取固定头字段（包括 `d + 46` 处的数据），但此时输入长度未必覆盖这些字段。

## 影响

损坏或恶意构造的 BMP 头可能令解码器在输入缓冲区边界之外读取数据，导致未定义行为或进程崩溃。

## 检查状态

由不可信头字段参与长度加法及其后续读取路径静态确认；没有修改项目代码。
