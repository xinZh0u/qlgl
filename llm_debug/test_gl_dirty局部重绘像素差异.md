# `test_gl_dirty` 局部重绘与全量重绘存在像素差异

## 现象

在启用 GL 后端、运行完整测试套件时，`test_gl_dirty` 的第 3 段动画对比会稳定失败：局部重绘结果与全量重绘结果有 1 个像素不同。其余已执行测试通过。

独立复现程序连续运行可得到同一结果：

- 场景：`test/web/flex/anim.html` 和 `anim.css`
- 窗口：360 × 260
- 时间：`s_now = 2100`（第 3 段 `step 1`）
- 脏区：`rect(-54,44,221,68)`、`rect(16,124,376,72)`、`rect(16,210,12,12)`
- 差异位置：`(22,125)`
- 局部重绘 RGB：`(6,232,248)`
- 全量重绘 RGB：`(6,232,249)`
- 差异仅为蓝色通道相差 1；对比忽略 alpha 通道。

复现命令：在已配置 GL 后端的构建目录运行 `ctest --output-on-failure -R '^test_gl_dirty$'`。也可运行独立复现程序 `/tmp/dbg_gl_dirty`。

## 已确认的范围

差异出现在 `.glow` 圆角矩形的抗锯齿边缘。`.glow` 的布局框为 `(16,124,376,72)`；其宽度大于视口宽度是场景中 `#root` 的 360px 内容区加左右 padding 的布局结果，并非目前已确认的根因。相同测试的 `step 0`、`step 2`、`step 3` 以及第 2 段循环未复现差异。

## 原因状态

已确认这是脏区重绘和全量重绘路径输出不一致的问题，但尚未证明导致单通道差异的具体计算步骤。当前证据不足以断言是裁剪、SDF 抗锯齿或颜色插值中的哪一项；需要进一步对比两条渲染路径在该像素处的片元覆盖率及绘制状态。
