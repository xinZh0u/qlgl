# 默认字体路径超长时被静默截断

> **核对 2026-11-15**：✅ 已修 —— `src/text/qlfont_ft.c:799-805` 超长直接失败并 `QL_LOGE`

## 问题

`ql_font_set_default_file()` 会先按完整路径加载并销毁一个探测字体，但保存路径时若长度超过 255 字节则静默截断到 255 字节。函数仍然返回成功并记录默认字体已设置，而后续工厂会尝试加载被截断的路径。

## 影响

合法的长路径会使设置函数报告成功，但之后 `ql_font_default()` 无法按该路径创建字体，转而回退到内置位图字体；日志与 API 返回值不能反映实际失败。

## 依据

- `src/text/qlfont_ft.c` 的 `s_default_path` 长度固定为 256。
- `ql_font_set_default_file()` 对超长路径将长度改为 `sizeof(s_default_path) - 1` 后复制，没有拒绝或报告截断。
- `default_factory()` 随后使用已截断的路径调用 `ql_font_ft_load()`。

## 验证状态

静态追踪确认设置与实际加载使用的路径可能不同；未在运行时创建超长路径复现。
