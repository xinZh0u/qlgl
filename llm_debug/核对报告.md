## 3. 本次补的 5 处

### 3.1 事件路径上限：从"静默截断"改为"构建期拒绝"

- `src/core/qlobject.c:232-262`：`ql_object_set_parent()` 计算
  `父链长度 + 子树高度`，超过 `QL_CFG_EVENT_PATH_MAX` 直接 `QL_ERR_INVAL` 并 `QL_LOGE`。
- `include/qlgl/qlconfig.h:39-45`：上限 8 → 16。
- 效果：**只要能建出来的树，事件就一定传得到根**；不再需要"警告一次"这种半吊子方案。
- 回归：`test/object/test_object_tree.c`（16 层可建、第 17 层被拒且树不变）、
  `test/object/test_object_event.c`（最深层 emit 能冒泡到根）。

### 3.2 RGB565/ARGB8888 的未对齐访问：堵在驱动入口

- `src/draw/qldisp.c:70-77`：16/32 位格式要求 `stride % 像素字节数 == 0`，否则 `QL_ERR_INVAL`。
  之前奇数 stride 能建出来，随后 `put_px` / `fill_row` 用 `uint16_t*` 直接解引用。
- 回归：`test/draw/test_canvas.c`（stride=21 被拒、stride=20 通过）。

### 3.3 内存驱动尺寸截断：判据从 `SIZE_MAX` 改为 `UINT32_MAX`

- `src/draw/qldisp.c:149-160`：`size64 > SIZE_MAX` 在 64 位平台恒假，随后 `(uint32_t)size64`
  静默截断 → 分配不足但驱动仍按原尺寸写。现在与 `ql_disp_buffer_size()` 用同一判据。
- 回归：`test_canvas`（`65536×16384` ARGB8888 → `NULL`）。

### 3.4 blob 的样式资源引用：补上漏掉的那一半

- `src/ui/qlui_blob.c:796-820`：校验 `bg_image` / `border_image` / `mask_image`
  （0xFFFF 或 `< text_count`），并拒绝图像条目 `name == 0xFFFF`
  （构建期会无条件 `text_offsets[name]`）。
- 回归：`test_ui_blob`（改坏样式下标 + 重算校验和 → 必须拒绝）、
  `test_image`（资源名改成 0xFFFF → 必须拒绝）。

### 3.5 附带修的两处

- `src/port/qlplatform_desktop.c:285-294`：桌面 CPU 窗口长期持有 `QLDraw2D`，
  每帧开始前同步 `scale_fx`，避免运行期 DPI 变化后整帧按旧缩放画。
- `CMakeLists.txt:97-104`：`QLGL_BUILD_TEXT_PARSER=OFF` 与 tests/examples/benchmark
  同时打开时在配置期 `FATAL_ERROR`（否则是一屏 undefined reference）。

## 5. 保留的 2 处降级（明确接受）

1. **CPU 图层 RGBA 分配失败**（`src/draw/qldraw2d.c:1201-1210`）
   两遍哑光已经画完，此时没有"原画布内容"可以回退；现在会 `QL_LOGE`。
   彻底修需要条带合成，而 blur 的垂直半径跨条带会改变结果 —— 收益不抵风险。
2. **滤镜临时缓冲分配失败**（`src/draw/qllayer.c:169-175`、`:339-345`）
   同上：现在是"有日志、跳过效果"，不是静默。条带分配可以降低失败概率，
   但要重写 box blur 的实现。

两处都只在**内存耗尽**时出现，正常路径不可达；在 48KB 堆的 MCU 上属于"本来就画不下"。
