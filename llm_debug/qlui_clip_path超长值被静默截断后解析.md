# qlui clip-path 超长值被静默截断后解析

> **核对 2026-11-15**：✅ 已修 —— `src/ui/qlui_parse.c:3059-3065` 超过 511 字节报语法错误

## 问题

`parse_clip_path()` 将 CSS 值复制到固定 512 字节数组时，循环达到容量后直接停止，但没有检查源字符串是否仍有剩余内容。随后解析被截断的前缀，并可能把它当作完整声明接受。

## 影响

超长 `clip-path` 声明的尾部会被忽略；例如合法前缀后面的额外无效内容可能不触发语法错误，导致构建期对实际 CSS 值的校验与作者预期不一致。

## 依据

- `src/ui/qlui_parse.c` 的 `parse_clip_path()` 在 `k + 1u < sizeof(t)` 时复制，循环结束后直接写入终止符。
- 截断时未报告容量错误，后续仅对 `t` 中的前缀执行语法校验。

## 验证状态

静态追踪确认超出 511 字节的尾部会被忽略；未构造专门的超长 CSS 动态测试。
