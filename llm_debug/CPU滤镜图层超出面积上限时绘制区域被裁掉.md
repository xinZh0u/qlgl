# CPU 滤镜图层超出面积上限时绘制区域被静默裁掉

> **核对 2026-11-15**：✅ 已修 —— `src/draw/qldraw2d.c:1078-1086` 返回空矩形 + 一次告警，`:1121-1123` 走普通绘制路径，内容不再被裁

## 问题

`cpu_layer_dev_rect()` 将 CPU 离屏图层面积限制为约 4096×1024 像素；当设备矩形的实际面积超过 4,194,304 像素时，代码直接把宽高改成 `4096` 和 `1024`，但保留原左上角。后续图层缓冲及合成都只覆盖这块缩小后的矩形，没有报错或回退到不使用图层的绘制路径。

## 影响

超大滤镜/变换/遮罩图层只有左上部分会被处理和合成，其余内容静默消失；面积限制还会改变实际图层的宽高比。

## 依据

- `src/draw/qldraw2d.c` 的 `cpu_layer_dev_rect()` 在 `(int64_t)w * h > 4096 * 1024` 时无条件设置 `w=4096`、`h=1024`。
- `cpu_layer_open()` 随后按该缩小矩形分配 matte，并将子树绘制裁剪到该范围。

## 验证状态

静态检查确认超过阈值后使用缩小矩形继续绘制；现有图层测试未覆盖超过 4,194,304 像素的图层，本次未做动态复现。
