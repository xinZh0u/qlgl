# `ql_canvas` 颜色矩阵的 32 位中间乘法可能溢出

## 问题位置

- `src/draw/qlcanvas.c`：`cm_apply()`
- `src/draw/qlcanvas.c`：`ql_canvas_set_color_matrix()`

## 问题说明

`ql_canvas_set_color_matrix()` 接受任意 12 个 `int32_t` 系数且不校验范围；`cm_apply()` 将这些系数与 0..255 的分量直接以 `int32_t` 相乘、累加，再右移。系数超过约 8.4 百万时，单项乘积就可能超出 `int32_t` 范围；多项累加也会溢出。颜色矩阵可由公开 API 调用方提供，因此该路径并不只限于内部 CSS 生成的系数。

## 影响

大幅度矩阵系数可能触发有符号溢出的未定义行为，令颜色计算结果不可靠。常见范围内的滤镜系数不受影响。

## 检查状态

由系数类型、未校验的 setter 和中间表达式类型静态确认；没有修改项目代码。
