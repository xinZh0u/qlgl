## 一、`src/core`（17）

| 报告 | 修法 |
|---|---|
| `qlstr` 长度溢出 | `set_n` 拒绝 `UINT32_MAX`；`append` 预检 `extra > UINT32_MAX - old - 1`；amortized 扩容翻倍前判断溢出，不再可能死循环；只读视图缩容时按容量截断拷贝 |
| `qlstr` 自追加悬空读 | `source_offset()` 判定源是否落在自身缓冲区：`set_n` 先把源搬到缓冲区开头；`append` 扩容后按偏移重定位。`set_static` 遇自身缓冲区退化成拷贝 |
| `ql_mem` 头部加法溢出 / 跟踪长度截断 | 头部 `size` 改 `uint64_t`；`alloc` 检查 `size > SIZE_MAX - sizeof(header)`；`realloc` 用 64 位旧长度 |
| `ql_mem_set_allocator` 混用分配器 | 三个回调必须同时非空，否则**整组**回落默认族并告警；`qlmem.h` 与手册同步改正 |
| `ql_fixed_div` 负数左移 UB | 改为 `int64_t` 乘法构造被除数，结果饱和 |
| `ql_fixed_from_int/to_int` 边界 | `from_int` 64 位乘法 + 饱和；`to_int` 全程 `int64_t`（`INT32_MIN` 不再取反溢出） |
| `ql_value_get_uint` FIXED 未换算 | 与 `get_int` 对齐为 `(uint32_t)ql_fixed_to_int(...)`；`get_fixed(UINT)` 也加 64 位饱和 |
| `QL_EVENT_FLAG_STOPPABLE` 未生效 | 新增 `stop_requested()`：只有登记 STOPPABLE 的事件才让 `stop_propagation` 生效 |
| 目标 stop 跳过默认处理 | `dispatch()` 先 `break` 出监听器循环、再执行默认处理；两种语义彻底解耦 |
| `ql_disconnect_all` 派发中回收槽位 | 派发期间只标记 `removed`，`ql_emit` 顶层统一 `conn_gc`；对象析构走新增的 `ql_event_force_disconnect_all()` |
| `ql_emit` 路径静默截断 | 深度超过 `QL_CFG_EVENT_PATH_MAX` 时打印一次警告（含上限值） |
| `ql_object_add_child(parent=NULL)` 销毁子对象 | 空父对象直接 `QL_ERR_INVAL` |
| `ql_input_push_move` 不同步按钮 | `track_state()` 对 MOVE 直接采用事件里的按钮快照 |
| `ql_input_push_text` 劈开 UTF-8 | 用 `ql_utf8_valid_len()` 截到码点边界 |
| `ql_anim` done 里重启同 key 被清 | 收尾时**先**清槽并复位 `used`，再调 `done`；`dur == 0` 路径同样调整 |
| `QLRect` 边界运算溢出 | `ql_rect_right/bottom` 改饱和加法；intersect/union 宽高用饱和减法 |
| `ql_rect_contains_round` 平方溢出 | dx/dy/radius 全程 64 位，内部边界也用饱和运算 |

回归用例：`test_str`、`test_object_event`、`test_input_queue`、`test_anim` 各补了针对性断言
（自追加、派发中断开重连、STOPPABLE、move 按钮、UTF-8 截断、done 重启）。

## 二、`src/draw`（17）

| 报告 | 修法 |
|---|---|
| BMP 头部 `14 + hdr_size` 溢出 | 改用 64 位比较；`INT32_MIN` 高度取反前拒绝 |
| BMP 调色板偏移 / COREHEADER 项宽 | 调色板偏移改为 `14 + hdr_size`（BITFIELDS 的 V3 头再 +12）；COREHEADER 用 3 字节项 |
| BMP BITFIELDS 只支持固定掩码 | 新增 `mask_to8()`：按掩码求移位与位宽并缩放到 8 位；同时支持 16 位 RGB565 BITFIELDS |
| PNG zlib 头跨 IDAT | `skip` 改为"流内剩余跳过字节数"，可跨块；头部校验用新 `png_idat_head()` 读跨块两字节 |
| QOI 未校验结束标记 | 像素解完后校验 `00×7 + 01`，缺失即失败（测试基样已补上标记） |
| libjpeg longjmp 后局部状态不确定 | `cinfo` / `JpegErr` 改堆分配，所有返回路径统一释放 |
| `ql_canvas` 毛玻璃半径溢出 | 半径先夹到 `min(max(rect.w, rect.h), 4096)`；外扩矩形用饱和运算 |
| `ql_canvas` 颜色矩阵乘法溢出 | `cm_apply()` 全程 `int64_t` |
| RGB565 未对齐 16 位访问 | `raw_px_get/set` 改用 `memcpy` |
| `ql_disp_buffer_size` 乘法溢出 | 64 位计算，超过 `UINT32_MAX` 返回 0 |
| `ql_disp_init_fb` / `mem_create` 尺寸溢出 | `min_stride`、`stride*height`、冗余系数均用 64 位校验 |
| `ql_disp_mem_save_ppm` 忽略写错误 | 检查 `fprintf/fputc/fclose`，失败返回 `QL_ERR_INVAL` 并打日志 |
| `ql_disp_set_scale` 不同步画布 | `QLCanvas` 新增 `disp` 反向引用 + `ql_canvas_scale_fx()`；布局、UI、Draw2D 统一从该函数取缩放；`ql_canvas_set_scale()` 解除跟随 |
| CPU 图层 RGBA 分配失败静默 | 明确 `QL_LOGE`（两遍哑光已画完，无内容可回退） |
| CPU 图层超面积被裁成 4096×1024 | 改为**不使用离屏图层**并告警：内容按普通路径完整绘制，不再裁掉/压扁 |
| 滤镜临时缓冲分配失败静默 | `ql_layer_blur` / `ql_layer_drop_shadow` 分配失败均 `QL_LOGE` |
| `ql_draw2d_text_layout` 固定 255 字节 | 超长显式长度改为按需分配完整副本，函数末尾释放 |

## 三、`src/text`（8）

| 报告 | 修法 |
|---|---|
| 默认字体路径静默截断 | 超长直接返回 0 并 `QL_LOGE`，不再记录半截路径 |
| 显式长度文本末尾 UTF-8 越界读 | 新增 `ql_utf8_decode_n(text, len, cp)`；bidi、整形、`wrap_next`、cluster 解码全部改用带长度版本 |
| UTF-8 辅助函数接受非法序列 | 抽出 `utf8_seq()`：拒绝 overlong、代理项、`> U+10FFFF`、`F5..F7`；`valid_len` 与 `encode` 共用同一套规则 |
| 字体家族字号缓存分配失败泄漏 | 缓存节点分配失败时销毁字体并返回 `NULL` |
| 字体注册超长路径污染注册表 | 长度检查提前到 `add_entry()` 之前 |
| FriBidi 分类函数按有返回值调用 | typedef 改为 `void`，删除所有返回值判断 |
| HarfBuzz 缓存字形指针失效 | 整形后先整行 `find_glyph_id()` 预热缓存，再第二遍取指针（第二遍不再插入/搬移） |
| 文本折行未计入 word-spacing / tab-size | `wrap_next()` 与绘制路径同规则：空格后加 `word_spacing`，`\t` 按 `tab_size` 个空格计宽 |

## 四、`src/ui`（9）

| 报告 | 修法 |
|---|---|
| 预编辑增量插入劈开 UTF-8 | 剩余容量截断后退回码点边界 |
| `ql_ui_input_set_value` / `build_internal` 按字节截断 | 两处都用 `ql_utf8_valid_len()` 退到码点边界 |

| `qlui_doc_load_mem` 未校验样式数量与文本索引 | 与上一条同一处实现：`node_count > 0 && style_count == 0` 直接拒绝，节点索引逐条检查 |

| 无效字体表泄漏 arena | 所有校验失败统一走 `fail:` 标签，同时释放 `doc` 与 `arena` |

## 五、`src/port`（13）

| 报告 | 修法 |
|---|---|
| Wayland 绑定版本不受 advertised 约束 | 每个 `wl_registry_bind` 用 `min(advertised, wanted)` |
| Wayland 触摸 ID 窄化 | 公开事件的 `touch_id` 改用**槽下标**（0..4）当稳定记号，不再窄化合成器 ID |
| Wayland 未知触摸 ID 的 move/up | 新增 `qlwl_touch_find()`：motion/up 只认已激活触点，未知 ID 直接忽略 |
| Wayland 窗口代理未判空 | surface / xdg_surface / toplevel / registry 创建后判空并走统一关闭路径 |
| Wayland shm pool 为空 | `wl_shm_create_pool` 判空，失败回收 mmap/fd |
| Wayland 剪贴板 source 悬空 | `cancelled` 回调里清 `clip_source` |
| Wayland 忽略 repeat_info | 记录 rate/delay 与重复键；`qlwl_pump()` 每帧 `qlwl_kb_repeat_tick()` 补发 key+text，key-up 停止 |
| Wayland 未处理 Shift/CapsLock | 新增 US 布局 Shift 符号表；字母用 `Shift ^ CapsLock`，符号按 Shift 映射 |
| Wayland 运行期重建失败 | `buffers_rebuild()` 改为"先建新、成功再换旧"，失败保留旧缓冲区；`wayland_flush()` 再判 `slot->data` |
| X11 与 Wayland 剪贴板 UTF-8 截断 | 两侧 set / 接收累积 / get 全部退到码点边界 |
| X11 fail 路径 `XFreeGC(NULL)` | 加空值判断（同时修正了错位的 `if` 嵌套） |
| X11 clip detach 未清异步状态 | `detach` 清 `waiting / in_ready / in_len / out_len / out` |
| X11 无 XIC 时 Latin-1 当 UTF-8 | 新增 `ql_x11_push_text_latin1()`，`XLookupString` 结果先转 UTF-8 |

## 七、遗留：`test_gl_dirty` 局部/全量重绘差 1 个像素

报告本身注明"尚未证明具体计算步骤"，且需要 GL/EGL 上下文复现。当前环境没有可用 GL
上下文（该测试走 `QL_TEST_GL_SKIP`），无法复现 `(22,125)` 处蓝色通道 ±1 的差异。

不盲目改渲染路径（GL 端全量/脏区共用同一套着色器，风险高于收益）。建议在有 GL 的机器上
按报告场景跑 `ctest -R '^test_gl_dirty$'`，先确认该像素在两条路径上的覆盖率与片元输入，
再决定是补脏区外扩 1px 还是修 AA 计算。
