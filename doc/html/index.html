从教程开始

第一次用？照教程顺序读，每章都有可以立刻编译运行的完整程序 （源码在 example/）。

基础知识QLGL 是一个用 C11 写桌面界面的库。它的想法很朴素：文本界面里最多的东西大概就是文字。这一章讲清 QLGL 文本的四条规则， 以及为什么它和浏览器不太一样。布局<img src="../img/03-layout.png" alt="布局" width="300"交互<img src="../img/04-interaction.png" alt="交互" width="260"动画<img src="../img/05-animation.png" alt="动画" width="300"换皮肤<img src="../img/06-theme-dark.png" alt="深色" width="260" <img src="../img/06-theme-light.png" alt="浅色" width="进阶前六章走完了"能写界面"。这一章讲清剩下的三件事：绘制后端怎么选、 数据是怎么流到屏幕上的、以及接下来该读什么。标签与语义这一章讲 HTML 标签。滚动overflow: visible 之外的两个值在这套实现里分工很清楚：与 Web 的差别这一章把"从浏览器稿子搬到 QLGL"会踩到的坑一次讲完。输入控件到这一章为止，界面里所有文字都是编译期定好的静态数据 —— 这一章讲唯一两个 例外：<input 与 <select。
