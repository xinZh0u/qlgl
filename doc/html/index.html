入门

从零写第一个界面：结构、文本、布局、交互、动画、换肤

基础知识QLGL 是一个用 C11 写桌面界面的库。它的想法很朴素：文本界面里最多的东西大概就是文字。这一章讲清 QLGL 文本的四条规则， 以及为什么它和浏览器不太一样。布局这是一个"顶栏 + 三张卡 + 一条半宽色带 + 一个绝对定位徽标"的界面。 布局代码只有 CSS，没有一行 C。交互这一章做三件事：鼠标移上去变样、按下去下沉、点击改文本。动画三类动效，全部只写 CSS：换皮肤三张图是同一份 HTML，只有 CSS 不同。例程目录里就是三份 CSS：进阶前六章走完了"能写界面"。这一章讲清剩下的三件事：绘制后端怎么选、 数据是怎么流到屏幕上的、以及接下来该读什么。

布局与文本

空白与上下标、Grid、表格、多栏、文本栈

空白与上下标到这一章为止，文本一直是"折叠空白 + 一行一段"。这一章加上两种"文本里的真内容"：Grid：二维布局，以及 border-image前面所有布局都是一维的：block 从上往下堆，flex 沿一条主轴排。表格状的界面 （卡片墙、后台管理页、"页头 / 侧栏 / 正文 / 页脚"）用一维工具拼要套好几层 wrapper —表格：display: table 全家 + colspan / rowspan在这之前，想画一个表格只能拿嵌套的 flex 拼：一行一个容器、每个格子固定宽度， 表头、跨行、跨列全得手算。B7 把真正的表格做进来了：多栏：column-count / column-width / column-rule一页要放"很多张小卡片"，最省事的不是 flex 也不是 grid，而是把容器分成几栏、 内容从上往下填，填满一栏换下一栏 —— 这就是 CSS 的多栏：文本栈：@font-face / 家族列表 / 真字重 / 连字 / 双向在 B8 之前，本库只有"正文 / 等宽"两级字体，font-weight: 700 是把字形抹粗一圈、 font-style: italic 是把整行剪切倾斜，阿拉伯文会排成一串孤立形。B

视觉与动效

毛玻璃、滤镜图层、变换、裁剪、效果检阅

毛玻璃叠在动的背景上这一章只讲一件事：一个半透明 + 高斯模糊的层，压在另一个"正在动"的层上， 下面变了上面的模糊会不会跟着变。答案是会，而且是每帧跟着变、不用整屏重绘。离屏图层：filter / mix-blend-mode / mask / 组透明度前面所有绘制都是"一个图元画一次"：背景一块、边框一圈、文字一遍。这条规矩 简单、快，而且 MCU 上不需要任何额外内存。但它表达不了四类效果：旋转光栅：transform: rotate() / skew() / matrix()到目前为止，transform 只做了两件事：translate()（加到绘制偏移上）和 scale()（绘制期绕中心缩放）。它们都是"画的时候顺手改一下坐标"， 一个图元画一次，零内存、零clip-path 的四种形状 · 纯颜色滤镜 · 字体变体这一章（B9，blob v34）补的都是"真实页面天天写、写了以前会报错"的东西：CSS 效果检阅：十六个例程前几章是按"补了什么"讲的（CSS3 补全、毛玻璃）。 这一章反过来：按"能看出效果的最小样本"讲 —— 每一个已支持的 CSS 效果都摆成 一格，旁边写着它该是什么值。跑起来一眼就能看出哪液态玻璃：blur + saturate + refract 的玻璃圆盘参考稿的滤镜链是 feGaussianBlur + feDisplacementMap：先轻度模糊，再按一张法线 图把像素位移。位移集中在轮廓附近，于是玻璃边缘看起来像一块有厚度的透镜。
