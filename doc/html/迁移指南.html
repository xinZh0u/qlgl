设计文档

从 Web 迁到 QLGL：写法对照与坑

CSS 也基本照抄。已经支持的大件（详见《CSS3 覆盖与裁剪》）：

状态：现行（2026-11-11）。目标读者：手上已有一份 HTML/CSS（或 React/Vue 的静态 结构 + 样式），想搬到 QLGL 上的人。

一句话：HTML/CSS 的"长相"几乎照搬，"行为"要换脑子。本库没有 JS 引擎、没有 DOM、 没有浏览器默认样式表那一堆隐式行为，取而代之的是 C 结构体、显式事件和"构建期报错"。

0. 三分钟判断这份页面能不能搬

你的页面里有 能不能搬 怎么办
<div> / <span> / flex / grid 布局、border-radius、阴影、渐变、filter、transform ✅ 直接搬 见 §1
<table> / 多栏正文 / <input> / <select> / <progress> / <details> / <dialog> ✅ 直接搬 标签与属性同名
@media (max-width: 600px) ✅ 直接搬（构建期切区间） §3
@font-face + font-family: A, B, sans-serif ✅ 直接搬 运行期要能打开那个字体文件（§4）
JS 驱动的交互逻辑（点击后改 DOM、列表渲染、表单校验） ⚠️ 要重写 换成 C：ql_ui_set_text() / ql_ui_repeat() / 事件回调（§5）
依赖浏览器默认样式（<h1> 是 32px、<p> 有 1em 上下边距…） ⚠️ 要显式写 本库的 UA 样式是有意收窄的（§2）
Canvas 绘图、SVG、position: fixed 的浮层动画、3D 变换 ❌ 明确不支持（构建期报错）
任何 javascript:、<script>、Web Components ❌ 永久红线（不做 JS 引擎）

1. 长相：几乎照搬

<!-- Web -->
<div class="card">
  <div class="title">标题</div>
  <p class="body">正文很长……</p>
</div>

<!-- QLGL：一模一样 -->
<div class="card">
  <div class="title">标题</div>
  <p class="body">正文很长……</p>
</div>

flex 全家 · grid 全家 · position: absolute/relative/sticky · overflow 分轴 · border-radius（含 a / b 椭圆角）· box-shadow（两层 + inset + spread）· text-shadow · outline · 线性/径向渐变 · background-image（cover/contain/具体尺寸）· border-image 九宫格 · filter（blur / drop-shadow / 八个颜色函数）· mix-blend-mode · mask · transform（translate / scale / rotate / skew / matrix）· clip-path （circle / ellipse / inset / polygon）· transition · @keyframes · 多栏 · 表格 · @font-face + 家族列表 + 整形 + RTL。

2. 五处最容易踩的"默认值不一样"

项 Web QLGL 为什么
white-space normal（自动折行） nowrap（一段文本就是一行） v0 的文本模型如此，改默认会让所有既有界面重排。要折行就写 white-space: normal —— 一行 CSS 换一个明确语义
UA 样式 <h1>=2em bold、<p>=1em 上下边距… 有意收窄：只保证"块/行内"与少量内边距 我们要的是"可预测"，不是"复刻每个浏览器的默认表"。显式写样式
display: inline 的宽度 由内容决定 同 但 <div> 默认 block、<span> 默认 inline，与 Web 一致
z-index / 层叠 完整 CSS 层叠上下文 支持 z-index，但只有一层绘制顺序（没有 3D 上下文、isolation） 一个节点一个盒，模型简单得多
百分比高度 需要父级有确定高度 同 但根元素可以直接 height: 100%（按视口解析）

迁移时最省事的做法：给 body/根容器加一条 * { box-sizing: border-box }，并显式写 white-space: normal（如果你原来靠自动折行）。

3. @media：构建期就切好区间

/* Web：一模一样 */
@media (max-width: 600px) {
  .card { width: 100%; }
}

区别在什么时候算：本库在 qltext 编译时就把每个区间各编译一份样式变体， 运行期只做"按视口宽选一个区间 + 三次数组取值"（没有条件表达式求值）。 所以：

  • 支持的断点类型只有 宽度（min-width / max-width / 区间）；
  • @media (prefers-color-scheme: dark) 之类构建期报错（要的是运行期环境判断， 换主题请用 CSS 变量 + 改一份变量表，见 §5.3）。

4. 字体：@font-face 能搬，但要能打开文件

@font-face { font-family: "My Sans"; src: url(/opt/fonts/MySans-Regular.ttf);
             font-weight: 400 }
@font-face { font-family: "My Sans"; src: url(/opt/fonts/MySans-Bold.ttf);
             font-weight: 700 }
body { font-family: "My Sans", "Noto Sans CJK SC", sans-serif; }
  • 构建期只收集声明（家族名/资源名进文本池），字体文件不进二进制；
  • 运行期 ql_ui_build() 时按表去打开文件（ql_font_family_register() 也可以手工注册）；
  • 打不开就报错并跳过那条，家族列表继续往后找 —— 所以最后一定写一个通用族兜底；
  • MCU 档建议直接用构建期位图字体（tools/qlfontgen），不要带 TTF。

5. 行为：从 DOM 操作换成 C

5.1 改文字

// Web
document.querySelector('.title').textContent = '新标题';

/* QLGL */
QLUINodeRT *t = ql_ui_find_by_tag(ui, QL_UI_TAG_DIV, 0);   /* 或用你自己的 id 表 */
ql_ui_set_text(ui, t, "新标题");
ql_ui_layout(ui, w, h);          /* 文本变了要重排 */

别每帧都 set_text + 全量 layout：布局 0.034 ms 量级虽小，但绘制会整块脏。 用 ql_ui_consume_dirty() + ql_ui_render_rect() 只重画变的地方。

5.2 列表渲染

// Web（框架帮你做的事）
items.forEach(it => list.append(row(it)));

/* QLGL：把模板写进 HTML，运行期复制 */
/* <div class="row"><span class="k">键 {i}</span><span class="v">{i}</span></div> */
QLUIRoot *ui = ql_ui_build(doc);
ql_ui_repeat(ui, ql_ui_root_node(ui)->first_child, (uint16_t)n_items);
ql_ui_layout(ui, w, h);
/* ⚠️ repeat 之后所有节点指针失效，要用 ql_ui_root_node() 重新取 */

数据不要"拼 HTML 字符串"再重新 ql_ui_load_text() —— 那会把整份 CSS 重新编译一遍。 ql_ui_repeat() 只复制节点（192 B/节点），样式是共享只读的。

5.3 换主题

// Web
document.documentElement.style.setProperty('--bg', '#222');

/* QLGL：CSS 变量在构建期就展开成了具体值（那是它便宜的原因），
   运行期换主题有两条路： */
/* ① 两份 doc，切换着用（最省事，适合"亮/暗"这种有限集合） */
ql_ui_free(ui); ui = ql_ui_build(theme_dark_doc);
/* ② 运行期改具体节点（适合只改几个重点色的场景） */
QLUIStyle *s = ensure_style_copy(...);   /* 用户侧通常用 ql_ui_set_text 那类 API */

5.4 事件

// Web
btn.addEventListener('click', () => { ... });

/* QLGL：一次性挂回调，回调里拿到节点指针 */
ql_ui_set_click_cb(ui, on_click, user_data);
static void on_click(QLUIRoot *ui, QLUINodeRT *node, void *ud)
{
    if (node->src != NULL && node->src->tag == QL_UI_TAG_BUTTON) { ... }
}

输入框同理：ql_ui_set_input_cb()；滚动、拖动、悬停都有对应入口（见《QLUI API 手册》）。

6. 构建：从"打包 + 浏览器"到"编译进固件"

# Web：静态资源原样部署，浏览器运行期解析 CSS
# QLGL：构建期编译成 C 数组，目标机零解析
qltext cc --html index.html --css style.css --name index --out build/ui
Web 概念 QLGL 对应
打包工具 qltext cc（把 HTML+CSS 变成 ui_index.c）
运行期文档 没有。想热重载就用 .qlui blob + ql_ui_load_file()（开发期用）
pkg-config / npm find_package(qlgl) 或 pkg-config qlgl
浏览器 devtools qltext check（构建期报错）、--dump x.ppm（离屏出图）、benchmark/bench

迁移前先跑一次降级报告：

qltext check --html index.html --css style.css --platform mcu
#   [裁掉] 表格（display: table 全家）  3 处 → QL_FEAT_CSS_TABLE=0 时构建期报错

它告诉你这份界面在目标平台上会撞到哪些裁剪项 —— 报出来的东西在真机上编不过， 不会"跑起来才发现不对"。

7. 逐项对照表（速查）

Web 写法 QLGL 写法 备注
display: flex; gap: 8px 同
display: grid; grid-template-columns: repeat(3, 1fr) 同
position: sticky; top: 0 同 挂在哪一级容器上很重要（§4.1）
overflow: auto 同（滚动条是覆盖式，不占布局）
transition: all .2s 同 可过渡属性少一些（见手册）
@keyframes + animation 同 steps() / cubic-bezier() 报错
filter: blur(4px) 同 走离屏图层
filter: grayscale(1) 同 不走图层（折成 3×4 矩阵，B9）
clip-path: circle(45%) / polygon(...) 同 见教程 25
transform: rotate(15deg) 同 走离屏图层 + 仿射重采样
transform: perspective(...) ❌ 3D 不排期（构建期报错）
::first-line / ::first-letter ❌ 明确报错；用 <span class> 手工包
document.querySelector ql_ui_find_by_tag() / 自己维护一张 id 表 没有选择器引擎
innerHTML = ... ql_ui_repeat() / ql_ui_set_text() 运行期不重新编译 CSS
localStorage 你自己的持久化（fopen / NVS / Preferences） 库不碰存储
requestAnimationFrame 主循环 + ql_ui_anim_tick() 静止时 0 帧

8. 迁移检查清单

  • [ ] 显式写 white-space: normal（如果原来靠自动折行）
  • [ ] 不再依赖 UA 默认字号/边距，样式写全
  • [ ] <script> 逻辑全部改写为 C 回调（没有 JS）
  • [ ] 列表用 ql_ui_repeat()，不要拼 HTML 再重新编译
  • [ ] qltext check --platform <目标> 跑一遍，把报出来的裁剪项处理掉
  • [ ] 目标机字体：要么 @font-face 能打开文件，要么用构建期位图字体
  • [ ] 动画/过渡用 transition 与 @keyframes（不要自己写定时器逐帧改样式）
  • [ ] 大列表考虑分页：节点数上限见 QL_CFG_UI_MAX_NODES
