# CSS3 补全：真实页面天天用的那几件

<img src="../img/14-css3.png" alt="::before 前缀 + 斑马纹 + 属性选择器 + hsl 配色" width="420">

完整程序：`example/14_css3/main.c`

这一章讲 2026-11 补进本库的一批 CSS 能力。它们都不是"高级特效"，
而是**写真实页面绕不开的东西** —— 缺了就得手工加 class、手工算颜色、手工插图标。

| 能力 | 不补的时候有多难受 |
|---|---|
| `::before` / `content` | 每个图标都要多写一个 `<span>`，HTML 立刻变脏 |
| `:nth-child(2n)` | 斑马纹要手工给每行加 `class="odd"/"even"` |
| `[data-*]` | 状态样式没法按数据属性写，只能再加 class |
| `min-width` / `max-width` | 窗口一窄，卡片被压成一条；一宽，又拉得难看 |
| `!important` | 被别处的规则覆盖时没有兜底办法 |
| `hsl()` | 配色要在脑子里做十六进制换算 |

---

## 1. `::before` / `::after`：构建期变成真节点

```css
.row::before { content: "• "; color: #8B949E; }
.row:first-child::before { content: "★ "; color: #E6C34A; }
```

本库的做法是**在构建期把它展开成一个真节点**（不是运行期"假装有个伪元素"）：

```
<div class="row">      →      <div class="row">
                                 <span class="__pe_0">★ </span>   ← 生成的
                                 <span>v0.3 布局与 flexbox</span>
                               </div>
```

所以：

- **运行期完全不知道有伪元素**，零成本、零分支；
- 它和普通节点一样参与布局、继承样式、被脏区覆盖；
- 用户的选择器匹配不到它（内部 tag 是 `#pe`，标签名不可能以 `#` 开头）。

三条必须知道的规则：

1. **必须写 `content`**，否则报错：`::before 规则缺少 'content'`。
   （浏览器是"没有 content 就不生成"，本库改成报错 —— 少一个"为什么没出来"的排查。）
2. **只支持纯文本**：`content: "★ "` 可以，`content: attr(x)` / `counter()` / `url()` 报错。
3. `content` 用在**普通元素**上直接报错（`'content' 只能用在 ::before / ::after 上`）。

`::before` 插在第一个孩子位置、`::after` 追加到末尾；**两者都不是"元素兄弟"**，
所以不会影响 `:first-child` / `:nth-child` 的计数。

## 2. 结构伪类：斑马纹一行搞定

```css
.row:nth-child(2n)   { background-color: #EEF2F7; }   /* 偶数行 */
.row:last-child      { border-color: #F6F8FA; }        /* 末条不画分隔线 */
.row:first-child     { color: #0969DA; }               /* 首条强调 */
```

支持的式子：`N`、`odd`、`even`、`an+b`、`-n+b`（**只算元素兄弟**，文本节点不算）。

同类还有 `:last-child` `:only-child` `:first-of-type` `:last-of-type`
`:only-of-type` `:nth-of-type()` `:nth-last-child()` `:nth-last-of-type()`
以及 `:not(...)`：

```css
.tag:not([data-kind]) { color: #57606A; }   /* 没有 data-kind 的那些 */
```

`:not()` 里只放**一个简单选择器**（tag / `.class` / `#id` / `[attr]`），不支持嵌套。

---

## 3. 属性选择器

```css
.row[data-state=warn]        { color: #9A6700; }
.row[data-state=warn]::before { content: "! "; }
.tag[data-kind=new]          { background-color: #DFF5E9; }
```

支持 `[a]`、`[a=v]`、`[a^=v]`、`[a$=v]`、`[a*=v]`、`[a~=v]`；
属性名自动转小写，值做 HTML 实体解码（`data-tip="a&amp;b"` 能匹配 `[data-tip="a&b"]`）。

这条配合 `::before` 很有用：**状态和图标都由数据驱动，HTML 里不用写死 class**。

---

## 4. `min-width` / `max-width`：窗口变窄不再被压扁

```css
#bar { width: 100%; min-width: 120px; max-width: 260px; }
```

语义与 CSS 一致，关键在**用哪个盒**：

| `box-sizing` | `min/max-width` 指 |
|---|---|
| `content-box`（默认） | 内容盒宽度（不含 padding / border） |
| `border-box` | 边框盒宽度（含 padding / border） |

百分比相对**父元素内容盒**；`min-height` / `max-height` 同理。
两个都是 px 且 `max < min` 时构建期报错（`max-width(120px) 小于 min-width(200px)`），
不给你一个"到底听谁的"的悬念。

---

## 5. `!important` 与 `inherit` / `currentColor`

```css
.hint { color: #6E7781 !important; }   /* 别的规则再想改也改不动 */
```

实现方式是**级联两趟**：普通声明先全部应用，带 `!important` 的再应用一遍。
所以你不用记"优先级三元组怎么算"——`!important` 永远赢，`!important` 之间仍按特异性比较。

```css
.a { border-color: currentColor; }   /* 跟随自己的 color */
.b { color: inherit; }               /* 显式继承（本来就是默认） */
.c { color: initial; }               /* 回到初值 */
```

## 6. `hsl()` 配色

```css
#fill { background-color: hsl(210, 90%, 55%); }
```

`hsl(h, s%, l%)` / `hsla(h, s%, l%, a)`，`h` 可以带 `deg`，可以负数（自动取模）。
`s` / `l` 是百分数。这样调色只改一个数（色相），不用手算十六进制。

## 7. 一条红线：关键帧里不能改 `width`

```css
/* ✗ 构建期报错：@keyframes 里不支持的属性 'width' */
@keyframes grow { from { width: 20%; } to { width: 92%; } }

/* ✓ 只能改绘制属性 */
@keyframes pulse {
  from { background-color: hsl(210, 90%, 55%); }
  to   { background-color: hsl(150, 70%, 42%); }
}
```

允许的键帧属性只有一组：`background*` / `opacity` / `transform` / `color` /
`border-color` / `border-radius` / `clip-path`。
理由是本库的红线 —— **动画零重排**：改宽度意味着每帧重新计算布局，
那就不再是"只重绘脏区"了。

## 8. 还没做的（别去试）

这一篇写的是 B2（选择器）。B3–B9 后来陆续落地，下表**已经清过一次**（2026-11-11）：

| 想写 | 现在 | 为什么 |
|---|---|---|
| `::first-line` / `::first-letter` / `::marker` / `::selection` | **明确报错并给替代写法** | 哪几个字落在第一行要等**折行**才知道，而样式是构建期编译成静态表的。用 `<span class=...>` 手工包那几个字 |
| `content: attr(x)` / `counter()` | 报错（只支持纯文本） | 等于引入一个小运行期求值器 |
| `:nth-child(2n+1 of .a)` | 报错 | L4 语法 |
| `filter: url(#svg)` / `backdrop-filter` 之外的 `mask-composite` | 报错 | 见教程 20 |
| `transform: perspective()` / `rotate3d()` | 报错 | 3D 要透视除法 + 深度排序 + 一个真正的合成器 |
| 三层及以上 `box-shadow` | 报错 | 只做两层（多写的报错，不静默丢弃） |
| `text-justify` / `text-align-last` / `hyphens` | 报错 | 只做 `text-align: justify`（末行固定不拉伸） |

**已经能用的**（当年这一节列过、现在全绿）：`:empty`、`text-align: justify`、
`box-shadow` 的 `spread`、`border-radius: a / b`（椭圆角，取两分量平均）、
`font` 简写、`word-wrap` 别名、`revert`、`filter` 全家（含 `blur()`）、
`transform: rotate()/skew()/matrix()`、`transition-delay`（长写与 `transition: … .2s` 简写都行）、
`clip-path` 的 circle/ellipse/inset/polygon、`small-caps` / `tabular-nums`。

完整清单与原因见 [CSS3 覆盖与裁剪](../手册/ui/CSS3覆盖与裁剪.html)。

## 单位与居中：`em` / `rem` / `vw` / `vh` / `margin: auto`

照搬真实页面时最常撞的两件事，现在都支持了。

```css
.card { padding: 1em; }              /* 相对**元素自己的**字号 */
.page { max-width: 60rem; }          /* 相对**根元素**字号 */
.hero { height: 40vh; }              /* 相对视口高度，窗口缩放自动跟着变 */
.box  { width: 320px; margin: 0 auto; }   /* 横向居中 */

/* 单条边也可以写 auto */
.sidebar-right { margin-left: auto; }     /* 靠右 */
```

| 单位 | 何时解析 | 说明 |
|---|---|---|
| `em` | **构建期**折成 px | 相对元素自己的 `font-size`（继承来的也算） |
| `rem` | 整棵树走完后折成 px | 相对根元素字号 —— 根的 `font-size` 自己也可能是 em，所以留到最后一趟 |
| `vw` / `vh` / `vmin` / `vmax` | **布局期** | 视口尺寸只有布局时才知道；`vmin`/`vmax` 取短边/长边 |
| `%` | 布局期 | 相对父容器内容宽（`margin` / `padding` 的百分比不支持） |

`margin: auto` 是**布局概念**：横向把剩余空间分掉（两边都 auto 就平分，
只剩一边 auto 就全给它）。所以它只对块级盒有效 —— 行内盒的宽度由内容决定，
没有"剩余"可分配。纵向 auto 按 0 处理：本库还不做外边距合并，单独实现一套
纵向居中容易和它打架，宁可明确不做。

```html
<div class="page">
  <div class="box">320px 宽，水平居中</div>
</div>
```

顺带一提 `aspect-ratio`（缩略图、卡片封面都用得上）：

```css
.thumb { width: 200px; aspect-ratio: 16 / 9; }   /* 高 = 200 × 9/16 = 112 */
.cover { height: 180px; aspect-ratio: 16 / 9; }  /* 宽 = 180 × 16/9 = 320 */
```

它只补**缺的那一边**：宽高都写了具体值时以具体值为准（与 CSS 一致）。
