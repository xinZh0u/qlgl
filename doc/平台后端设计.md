# 平台后端设计（`QLPlatform`）

目标：应用只写 `qlgl_init()` + `ql_window_*`，**平台差异（X11 / Wayland / MCU 板级）
全部收在一张回调表里**。`QLWindow` 不知道底下是什么，只调 `QLPlatform`。

```
应用
 └─ QLWindow（主循环、输入汇、IME/剪贴板、脏区重绘）
     └─ QLPlatform（窗口/显示、事件泵、绘制呈现）
         ├─ 桌面：X11/Wayland + GL 或 CPU 光栅
         └─ MCU ：板级显示 flush + 按键/触摸 + tick
```

## 1. 回调表

```c
typedef struct QLPlatform {
    const char *name;

    QLPlatformWindow *(*window_open)(const char *title, ql_coord_t w, ql_coord_t h,
                                     int backend);
    void (*window_close)(QLPlatformWindow *pw);

    int  (*poll)(QLPlatformWindow *pw);          /* 1 = 继续，0 = 已关 */
    int  (*wait)(QLPlatformWindow *pw, int timeout_ms);
    void (*size)(QLPlatformWindow *pw, ql_coord_t *w, ql_coord_t *h);
    int  (*resize_pending)(QLPlatformWindow *pw);

    int  (*begin)(QLPlatformWindow *pw, ql_color_t bg, const QLRect *dirty, int n);
    QLDraw2D *(*draw)(QLPlatformWindow *pw);
    void (*end)(QLPlatformWindow *pw);

    void (*set_vsync)(QLPlatformWindow *pw, int on);
    int  (*dump_ppm)(QLPlatformWindow *pw, QLUIRoot *ui, ql_color_t bg,
                     const char *path);

    void (*attach_clipboard)(QLPlatformWindow *pw, QLUIRoot *ui);
    void (*attach_ime)(QLPlatformWindow *pw, QLUIRoot *ui);
    void (*set_ime_spot)(QLPlatformWindow *pw, ql_coord_t x, ql_coord_t y,
                         ql_coord_t h);
    void *(*native)(QLPlatformWindow *pw, const char *what);   /* "gl" */
    uint32_t (*frame_us)(QLPlatformWindow *pw);
    uint32_t (*swap_us)(QLPlatformWindow *pw);
} QLPlatform;
```

`begin(..., dirty, n)`：`n == 0` 表示整屏；返回 1 表示后端要求整屏重画。
CPU 后端在 `begin` 里清脏区、`end` 里把脏区 flush 给显示驱动即可。

## 2. 选择后端

1. 应用在 `qlgl_init()` **之前**调 `qlgl_set_platform(&my_platform)`（测试/模拟器/多后端）；
2. 否则用 `qlgl_platform_default()`（弱符号）：
   - 桌面构建：`ql_platform_desktop()`（X11 → Wayland → 内存离屏；GL 或 CPU）；
   - MCU：板级文件定义**同名强符号**，覆盖弱符号：

```c
/* port/myboard/qlplatform_board.c —— 链接进来即可，应用层不用改 */
const QLPlatform *qlgl_platform_default(void) { return &board_platform; }
```

`QLWindow` 通过 `qlgl_platform()` 取当前后端；桌面默认后端已包含 GL 与 CPU 两套。

## 3. MCU 板级骨架

```c
typedef struct {
    QLDispDriver disp;       /* ql_disp_init_fb 初始化：静态 RGB565 帧缓冲 */
    QLCanvas     canvas;
    QLDraw2D     d2d;
    QLRect       flush;
    int          full;
} BoardWindow;

static QLPlatformWindow *board_open(const char *title, ql_coord_t w, ql_coord_t h,
                                    int backend)
{
    (void)title; (void)backend;
    BoardWindow *b = &s_board;              /* 单屏：静态对象，零分配 */
    static uint16_t fb[320 * 240];
    if (ql_disp_init_fb(&b->disp, fb, 320 * 2, w, h, QL_COLOR_RGB565, board_flush))
        return NULL;
    ql_canvas_from_disp(&b->canvas, &b->disp);
    ql_draw2d_canvas_init(&b->d2d, &b->canvas);
    return (QLPlatformWindow *)b;
}

static int board_poll(QLPlatformWindow *pw)
{
    BoardWindow *b = (BoardWindow *)pw;
    board_read_keys();                      /* 中断里入环形队列，这里搬到 ql_input_push_* */
    return !s_power_off;
}

static int board_begin(QLPlatformWindow *pw, ql_color_t bg, const QLRect *dirty, int n)
{
    BoardWindow *b = (BoardWindow *)pw;
    if (n == 0) { ql_canvas_clear(&b->canvas, bg); b->full = 1; return 0; }
    for (int i = 0; i < n; i++) ql_canvas_fill_rect(&b->canvas, dirty[i], bg);
    b->full = 0;
    return 0;
}

/* flush：把 dirty 矩形推进 SPI/DMA；frame_us/swap_us 可以留 NULL */
```

`wait()` 在裸机上一般是空操作或 `WFI`；`poll()` 里读按键并
`ql_input_push_key()`（注意：**不要在 ISR 里直接 push**，主循环里搬）。

## 4. 桌面 CPU 光栅

`QLPlatform` 的默认桌面实现里 `window_open(..., QL_WINDOW_CPU)` 走：

- `ql_disp_x11_create()`（X11）或 `ql_disp_wayland_create()`（Wayland）；
- `ql_canvas_from_disp()` + `ql_draw2d_canvas_init()`；
- `begin` 清脏区、`end` 调驱动 `flush()` / `flush_done()`；
- 窗口缩放：`resize_pending` 里重建画布，`QLWindow` 重新布局。

调试：`QLGL_WINDOW_CPU=1 ./example_00_hello` 强制走 CPU 路径，用来和 GL 对照。

## 5. 测试

`test/web/test_window_fake.c` 用假平台（内存显示 + 脚本输入）验证：

- `qlgl_set_platform(&fake)` 后 `ql_window_create()` 走假后端；
- `ql_window_poll()` 把输入队列派发到界面层并触发点击回调；
- `ql_window_dump_ppm()` 写出非空 PPM；
- `ql_window_set_ui()` 换界面、`ql_window_quit()` 退出。

这个假后端就是 MCU 平台的"PC 版"：换成真实显示 flush / 按键读取即可。
