旋转光栅：transform 的 rotate / skew / matrix
先合成再重采样
1. rotate() —— 转的是"渲染结果"，文字和圆角一起转
0°
15°
45°
90°
180°
每个标签都是一整个元素（含文字、圆角），转完再贴回去
2. transform-origin —— 换个旋转中心，同样的角度落在不同地方
中心
左上
右中
都是 rotate(30deg)，只有 transform-origin 不同
3. skewX() / skewY() —— 斜切，就是错切矩阵
skewX(18deg)
skewY(18deg)
skewX(-18deg)
4. matrix(a,b,c,d,e,f) —— 旋转 + 斜切 + 平移一次说完
matrix(1,0.25,-0.35,1,10,6)
matrix(0.9,-0.3,0.3,0.9,0,0)
第一个是"斜切 + 平移"，第二个是 rotate(-18deg) 的矩阵写法
5. 和图层特效叠加：旋转 + 模糊 / 旋转 + 阴影 / 旋转 + 圆角裁切
blur
shadow
round
圆角是"先裁再转"（CSS 语义），所以转 45° 看到的是圆的边缘，不是方形的角
6. 表盘指针：同一套样式，只改一个角度
指针的 transform-origin 在圆心那一端，所以是"绕轴转"
实现方式：带 transform（旋转/斜切/矩阵）的元素先把自己的子树 正常画进一块临时 RGBA 图，再按 3×3 矩阵做一次**仿射重采样**贴回去。 所以 rotate 出来的文字是"转过的文字"（不是重新排一次版）， 代价是一块元素大小的缓冲 + 一次双线性采样；MCU 档可以把整套 transform 重采样裁掉，只留 translate/scale。
