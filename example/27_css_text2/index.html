B3 文本细节：word-spacing / tab-size / text-decoration-*
三样都只影响绘制
1. word-spacing：只加在**空格之后**（字母之间不变）
The quick brown fox jumps
The quick brown fox jumps（word-spacing: 6px）
The quick brown fox jumps（word-spacing: -2px）
2. tab-size：同样是 '\t'，2 / 8 个空格宽
A B C
A B C
3. text-decoration-line：underline / overline / line-through / 组合
下划线
上划线
删除线
上下都有
4. text-decoration-style：solid / double / dotted / dashed
solid
double
dotted
dashed
5. text-decoration-thickness / -color / text-underline-offset
2px 红线
4px 绿线
下移 6px
装饰线也是"用 fill_rect 拼"的：double 两条、dotted 一点一点、dashed 段+缝， 所以 CPU 与 GPU 逐像素一致，MCU 上也不需要新图元。
