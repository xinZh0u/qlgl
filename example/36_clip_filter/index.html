5. 纯颜色 filter：不进离屏图层，折成一个 3×4 颜色矩阵
原色
grayscale(100%)
saturate(0.4)
invert(100%)
hue-rotate(90deg)
contrast(180%)
sepia(100%)
gray+invert 30%
这些只改颜色，不需要"先把子树合成到一张图"，所以 CPU 逐像素过矩阵、 GPU 用 uniform —— 每个元素都不多一块缓冲。含 blur() / drop-shadow() 的才走离屏图层（见例程 31）。
6. text-align: justify · small-caps · tabular-nums · 椭圆圆角 · 阴影 spread
justify：两端对齐会把除最后一行之外的每一行拉满整行宽度，末行保持左对齐。 这一段足够长，所以第一行与第二行都会被拉伸到边缘，最后一行则不会。
只有一行的时候，justify 与左对齐完全一样 —— 这是 CSS 的语义，不是 bug。
