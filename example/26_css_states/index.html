B2 状态选择器：:disabled / :checked / ::placeholder
纯 CSS
1. :disabled —— 同样的按钮，禁用态自动变灰、不再响应
2. 输入框：可编辑 / disabled / readonly 外观
3. :checked —— 点一下复选框，勾选样式立刻生效
4. :enabled —— 只有可用的那一个高亮
5. ::placeholder —— 占位文字用独立样式（灰、斜体）
这一页所有变化都由 CSS 完成：`:disabled` / `:checked` 在构建期各编出一份样式变体， 运行期只切换一个状态位。::placeholder 也是构建期把声明合并进"占位样式"。
