B4 绘制细节：border-style 与 outline
两样都只改绘制，不动布局
1. border-style：solid / dashed / dotted（同样 2px）
solid
dashed
dotted
2. 图案跟着线宽缩放：1px 与 4px 的 dashed
1px dashed
4px dashed
2px solid
3. 和 border-radius 一起用：圆角按直角画（已知差异）
radius 10
radius 10
radius 10 solid
4. outline-offset：0 / +5 / -4（负值压进边框里）
offset 0
offset 5
offset -4
5. focus 环：点一下"输入框"，outline 跟着 :focus 出现
outline dashed
6. border-style: none 不占位：两个盒子一样大，左边没有边
none (4px)
solid (2px)
虚线/点线是"沿边切段填色"实现的：CPU 与 GPU 走同一条 fill_rect 路径， 所以两条后端逐像素一致（golden 里 b4 页 0.5% 差异，全在圆角抗锯齿上）。
